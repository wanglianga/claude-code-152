# 焕新到家 · 城市二手家具寄卖平台

面向城市居民的一站式二手家具寄卖平台：居民提交寄卖申请 → 估价师上门估价 → 平台仓管清洁/补漆/拍照上架 → 买家下单 → 配送团队交付 → 客服协同处理异常与售后 → 财务结算 → 运营按品类沉淀数据决策「入仓寄卖 or 同城自提」。

## 技术栈

| 层 | 技术 |
| --- | --- |
| 前端 | React 18 + Vite + Ant Design 5 + React Router 6 |
| 后端 | NestJS 10 + TypeORM |
| 数据库 | PostgreSQL 16（本地开发用 15 亦可） |
| 部署 | Docker Compose（web=Nginx、server=NestJS、db=PostgreSQL） |

## 一键启动（Docker）

```bash
docker compose up --build
```

启动后访问：

- 平台入口（前端）：http://localhost:8080
- 后端 API：http://localhost:3000/api

首次启动时后端自动建表并写入种子数据（演示账号 + 全流程演示数据）。

## 本地开发


## 一条龙的验证路径（建议按角色依次体验）

1. **卖家 seller1** →「提交寄卖」填写沙发信息（可上传瑕疵照片）→ 列表出现「待估价」。
2. **估价师 appraiser1** →「估价任务」预约上门 →「上门估价」填写结构/污渍/异味/虫蛀/板材变形/搬运难度，给出寄卖价、最低成交价、佣金比例、翻新建议与预估翻新成本。
   - 用 **seller2** 提交的申请会要求勾选「已完成严格验真」才能提交（因其历史反悔+描述不符记录）。
3. **卖家** → 寄卖详情「接受估价」选择入仓或放家中 → 自动生成清洁/补漆/拍照备货任务。
4. **仓库 warehouse1 / 翻新师 refurbisher1** →「库存与备货」完成备货任务并登记成本；补漆成本超过预估 120% 会自动生成「翻新成本超预期」工单；清洁+拍照完成后「上架」（上架价不得低于最低成交价）。
5. **买家 buyer1** →「逛商城」下单，选择楼层/电梯/拆装/旧家具搬出/车型与预约时间，配送费按规则实时计算。
6. **配送 delivery1** →「配送中心」安排配送 → 出发 → 送达；若「配送失败」（如沙发进不了电梯）会自动生成异常工单。
7. **买家** →「我的订单」确认收货（自动生成结算单），或发起「色差/磕碰/退货」售后。
8. **客服 cs1** →「异常工单」接手 → 时间线记录协同过程 → 选择处置动作结案（如赔付买家/同意退货/确认卖家反悔/重新调度），系统自动联动订单、商品、寄卖单状态并生成/追加结算。
9. **运营 ops1** →「品类分析」查看各品类成交周期、翻新投入、退货率、配送失败率与入仓/自提建议；「卖家风险」查看信用评分；「结算管理」核对每笔费用来源并确认结算。
10. **卖家** →「我的结算」查看成交价、佣金、翻新费、仓储费、配送费、售后赔付与实收明细。

## 平台计费规则（演示环境统一约定）

- **平台佣金** = 成交价 × 估价单约定比例（10%~20%）
- **配送费** = 车型基价（小面包 80 / 中货 150 / 大货 260）+ 无电梯楼层费 10 元/层（1 层以上）+ 拆装 60 + 旧家具搬出 50（买家支付，平台代收转付配送方）
- **仓储费** = 入仓天数 × 3 元/天（仅入仓寄卖计收，卖家承担）
- **翻新费** = 备货任务实际成本合计（卖家承担）；实际成本超预估 120% 自动生成预警工单
- **售后赔付** = 客服结案时登记，可指定平台或卖家承担，计入结算单
- **卖家实收** = 成交价 − 佣金 − 翻新费 − 仓储费 − 卖家承担的赔付
- **卖家信用评分** = 反悔×2 + 描述不符×2 + 售后争议×1，≥2 分再次寄卖强制严格上门验真
- **入仓建议规则**：平均成交周期 ≤30 天 且 退货率 <15% 且 配送失败率 <20% →「适合入仓寄卖」，否则「建议同城自提」

## 目录结构

```
├── docker-compose.yml      # 一键启动（db + server + web）
├── server/                 # NestJS 后端
│   ├── src/entities/       # 用户/寄卖/估价/家具/备货/订单/配送/工单/结算 实体
│   ├── src/auth/           # JWT 登录 + 角色守卫
│   ├── src/consignments/   # 寄卖申请 + 估价 + 卖家风险校验
│   ├── src/inventory/      # 库存备货 + 上架 + 实物不符上报
│   ├── src/orders/         # 商城 + 下单 + 确认收货
│   ├── src/delivery/       # 配送调度 + 失败上报
│   ├── src/issues/         # 异常工单 + 结案业务联动
│   ├── src/settlements/    # 结算单生成/追加赔付/结算
│   ├── src/analytics/      # 品类分析 + 卖家风险
│   └── src/seed/           # 种子数据（演示账号 + 全流程数据）
└── web/                    # React 前端（按角色分页面）
```
